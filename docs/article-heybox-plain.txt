先说要达成什么效果：我打一段字，她的声音念出来。 不打字的时候，还能接进语音对话客户端，当朗读后端用。

不是网页里那种几十秒试听的 demo，是本机跑的、随便念多长都行。

折腾了一晚上，中间踩了三个坑。记录一下，想弄的人可以直接抄。

需要什么

硬件门槛：一张显卡。我的是笔记本的 RTX 5060（8G 显存），够用，但训练和推理的时候不能同时开太多别的。

软件门槛：得会敲几行命令。不用会写代码，但要能照着步骤复制粘贴，看得懂报错在说什么。

整体流程是这样：

1. 准备语音素材（要干净的人声，最好 5 秒以上一条，多准备几十条）
2. 用 GPT-SoVITS 训练出一个音色模型
3. 起一个服务，让它能接收文字、返回语音
4. （可选）接进语音客户端，让它自动念

第 2 步官方有教程，我这里主要记录第 3 步——这一步是最容易卡住的，我卡了一整晚。

坑一：官方接口，标准客户端不认

GPT-SoVITS 自带一个服务（api_v2），启动之后是这样调的：

　　GET /tts?text=你好&text_lang=zh&ref_audio_path=...&prompt_text=...

能用，但现在的语音客户端普遍期望的格式是：

　　POST /v1/audio/speech
　　{"input": "你好", "voice": "角色名", "response_format": "mp3"}

一个是 GET 加一堆参数，一个是 POST 传 JSON。对不上，客户端压根发现不了你的服务。

坑二：浏览器连不上

如果你用的是网页版的语音前端，控制台会报一大段红字，核心意思是：

　　has been blocked by CORS policy: No 'Access-Control-Allow-Origin' header

官方这个服务是给本机脚本用的，没处理浏览器直连的情况。

坑三：格式不认

这个最阴。请求发出去了，也返回 200 成功，但前端就是不出声，报一句：

　　invalid data format

原因是它返回的是 wav 原始数据，而很多前端只认 mp3。

三个坑叠在一起，结果就是：服务跑得好好的，客户端就是不认。

怎么解决的

社区里有人做了改好的接口文件，直接替换掉官方的就行——如果你只是想在本机调着玩，这个方案最省事。

但它改的是接口的易用性，格式还是老样子，标准客户端还是连不上。我要的是后面那个，所以自己写了个中间层：

　　语音客户端 ──标准格式──> 中间层 ──官方格式──> GPT-SoVITS

这个中间层干三件事：把标准格式翻译成官方认识的参数、补上浏览器需要的头、把 wav 转成 mp3。

好处是不用动 GPT-SoVITS 本身的任何文件——它以后升级，我这边不受影响。

配置很简单，就一个文件：

　　{
　　  "defaultVoice": "角色名",
　　  "voices": [
　　    {
　　      "id": "角色名",
　　      "refAudio": "参考音频.wav",
　　      "promptText": "参考音频里说的那句话"
　　    }
　　  ]
　　}

想换角色，就在这个文件里加一条，请求里指定用哪个名字就行。

折腾过程中还踩了三个小坑

一、mp3 转码不一定成功。 我一开始写死了用 libmp3lame 编码器，在我机器上好好的，换台机器直接报错——不是每台机器装的 ffmpeg 都带这个编码器。后来改成三级回退，都不行就退回 wav。

二、并发会把显存打爆。 客户端念长文本的时候会切成好多段一起发请求，几个请求同时进显卡直接崩。改成排队一个一个来，慢一点但稳。

三、偶尔念到一半断了。 没什么好办法判断，我用了个笨招：按字数估一下音频至少该有多长，明显短了就重新合成一次。不完美，能救回大部分。

说说训练这部分

训练也有坑，主要是官方的流程要手动跑六个脚本，中间错一步就得从头来。

所以我把整个流程也包成了一个命令，跑完自动接力下一步，挂了能从断掉的地方继续。

六个步骤是：切片 → 语音识别打标 → 提取特征 → 训练音色模型 → 训练语言模型 → 登记产物。

我拿一段 10 秒的音频试过完整流程，能跑通，最后产出大概 450MB 的模型文件。

素材质量比数量重要得多——宁可 50 条干净的，不要 200 条带噪音的，后者训出来会有杂音。

最后

两个东西都在 GitHub 上，都是开源的：

- 训练编排器（从素材到模型）
- 语音网关（把模型接进各种客户端）

搜 zyqchanel-06 就能看到。有不清楚的评论区问，我看到会回。

哦对，显卡不够的话其实也能玩——推理可以用 CPU，就是慢。训练才必须要显卡。
